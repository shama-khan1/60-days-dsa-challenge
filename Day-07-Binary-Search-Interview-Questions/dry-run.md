# Dry Run

## Example

```text
Array

Index : 0   1   2   3   4   5
Value :10  20  20  20  30  40

Target : 20
```

---

## Step 1

Find First Occurrence

```text
First = 1
```

---

## Step 2

Find Last Occurrence

```text
Last = 3
```

---

## Step 3

Apply Formula

```text
Count = Last - First + 1
```

```text
Count = 3 - 1 + 1
```

```text
Count = 3
```

---

## Final Output

```text
3
```
